# Desktop connection lifecycle

- Electron main owns connection credentials, durable generations, private host IPC and recovery. Renderer uses the typed preload API and receives redacted status, never stored secret values.
- `connection-store.ts`, `credentials.ts`, `connection-service.ts` and `recovery-store.ts` re-export the common implementations in `packages/megaladata-host/src/connection`. `desktop-service.ts` supplies Electron paths and safeStorage to `createMegaladataHost`; `host-port.ts` re-exports the common handler over the structural HostPort contract. Existing connection tests here exercise those common implementations through the Desktop exports.
- Linux intentionally stores secrets as plaintext configuration with files `0600`, directories `0700`. Production profile is `${XDG_CONFIG_HOME:-~/.config}/com.megaladata.aiagent`; do not relocate it when changing the installation directory. Other channels have separate profiles.
- Lease a connection generation for the whole active drain. Save pending changes durably and activate only at a safe boundary. Attempts use isolated UUIDs; retain receipts across recovery.
- Persist/fsync recovery intent before tool dispatch. By default an uncertain operation does not require confirmation and does not block the next connection generation: Desktop does not enable `strictRecovery`. `acknowledgeRecovery` and the strict-mode journal remain for acceptance. Operations are not retried automatically. The recovery button in settings is hidden.
- Setup asks exactly API key, Megaladata URL, username and password. Defaults come from Product; password is empty without placeholder. The files folder derives from username without an availability probe. Model/provider connection stays in existing provider settings.
- Preserve explicit proxy environment and the loopback bypass for the Megaladata runtime. System proxy for model and OAuth traffic is applied to the Desktop sidecar and CLI, not to runtime children. See `docs/superpowers/specs/2026-09-23-system-proxy-v2.md`.
- Run `bun test src/main/megaladata` and `bun typecheck` from `packages/desktop`. Real GUI tests use isolated profiles; never restart or overwrite the user's running session for debugging.
